Pipecat pipelines are chains of `FrameProcessor`s. Smaran ships a Python processor that hooks the `UserTranscriptFrame` and the `LLMFullResponseEndFrame` events.

## Install

```bash
pip install smaran-pipecat
```

## Pipeline

```py
from pipecat.pipeline.pipeline import Pipeline
from smaran_pipecat import SmaranProcessor

smaran = SmaranProcessor(
    api_key=os.environ["SMARAN_API_KEY"],
    session_id=call_sid,
)

pipeline = Pipeline([
    transport.input(),
    stt,
    smaran,   # <-- captures user transcripts, injects recall context
    llm,
    tts,
    transport.output(),
])
```

The processor reads `UserTranscriptFrame`, commits it to Smaran, and pushes a `LLMMessagesFrame` with recalled context appended to the system prompt before the LLM runs.

## Session lifecycle

The Pipecat processor holds its own session buffer. On `UserStartedSpeakingFrame` it opens a partial-ingestion window; on `UserStoppedSpeakingFrame` it commits. No manual open/close needed.

<Callout tone="warn" title="Python SDK vs TS SDK">
`smaran-pipecat` is a thin Python wrapper around the REST API — the primary SDK is TypeScript. If you find a bug in the Python wrapper, file it against the pipecat adapter package, not the core SDK.
</Callout>
