Simple memory retrieval examples for getting started with the list memories endpoint.

## Basic Usage

<Tabs>
  <Tab title="TypeScript">
    ```typescript
    import Engram from 'engram';

    const client = new Engram({
      apiKey: process.env.ENGRAM_API_KEY!
    });

    const response = await client.documents.list({ limit: 10 });
    console.log(response);
    ```
  </Tab>
  <Tab title="Python">
    ```python
    from engram import Engram
    import os

    client = Engram(api_key=os.environ.get("ENGRAM_API_KEY"))
    response = client.documents.list(limit=10)
    print(response)
    ```
  </Tab>
  <Tab title="cURL">
    ```bash
    curl -X POST "https://api.engram.ai/v3/documents/list" \
      -H "Authorization: Bearer $ENGRAM_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"limit": 10}'
    ```
  </Tab>
</Tabs>

## With Custom Parameters

<Tabs>
  <Tab title="TypeScript">
    ```typescript
    const response = await client.documents.list({
      containerTags: ["user_123"],
      limit: 20,
      sort: "updatedAt",
      order: "desc"
    });

    console.log(`Found ${response.memories.length} memories`);
    ```
  </Tab>
  <Tab title="Python">
    ```python
    response = client.documents.list(
        container_tags=["user_123"],
        limit=20,
        sort="updatedAt",
        order="desc"
    )

    print(f"Found {len(response.memories)} memories")
    ```
  </Tab>
  <Tab title="cURL">
    ```bash
    curl -X POST "https://api.engram.ai/v3/documents/list" \
      -H "Authorization: Bearer $ENGRAM_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "containerTags": ["user_123"],
        "limit": 20,
        "sort": "updatedAt",
        "order": "desc"
      }'
    ```
  </Tab>
</Tabs>

<Info>
  Start with small `limit` values (10-20) when testing to avoid overwhelming responses.
</Info>
