## Python SDK

## Installation

```sh
# install from PyPI
pip install --pre engram
```

## Usage


```python
import os
from engram import Engram

client = Engram(
    api_key=os.environ.get("ENGRAM_API_KEY"),  # This is the default and can be omitted
)

response = client.search.documents(
    q="documents related to python",
)
print(response.results)
```

## JavaScript SDK

## Installation

```sh
npm install engram
```

## Usage

```js
import Engram from 'engram';

const client = new Engram({
  apiKey: process.env['ENGRAM_API_KEY'], // This is the default and can be omitted
});

async function main() {
  const response = await client.search.documents({ q: 'documents related to python' });

  console.debug(response.results);
}

main();
```
