## Python SDK

## Installation

```sh
# install from PyPI
pip install --pre smaran
```

## Usage


```python
import os
from smaran import Smaran

client = Smaran(
    api_key=os.environ.get("SMARAN_API_KEY"),  # This is the default and can be omitted
)

response = client.search.documents(
    q="documents related to python",
)
print(response.results)
```

## JavaScript SDK

## Installation

```sh
npm install smaran
```

## Usage

```js
import Smaran from 'smaran';

const client = new Smaran({
  apiKey: process.env['SMARAN_API_KEY'], // This is the default and can be omitted
});

async function main() {
  const response = await client.search.documents({ q: 'documents related to python' });

  console.debug(response.results);
}

main();
```
